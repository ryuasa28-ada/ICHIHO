## 書き出し設定

**1280 × 720 px / JPEG 品質 82**。元画像から変換する場合は次のコマンドで揃えられます。

```bash
sips -s format jpeg -s formatOptions 82 -Z 1280 元画像.png --out assets/photos/gallery-04.jpg
```
