# 写真素材（差し替え用）

リユース事業ページ（`business-reuse.html`）で使用する写真の置き場所です。
現在入っているファイルはすべて **仮のプレースホルダー** で、実写に差し替える前提です。

## 差し替え手順

1. このフォルダに、同じファイル名で実写を置く（拡張子は `.jpg` / `.webp` などでOK）
2. `reuse-lp.jsx` 冒頭の `PHOTOS` 定数でパスと `alt` を書き換える

```js
const PHOTOS = {
  slides: [
    { src: "assets/photos/slide-01.svg", alt: "出張買取の様子" },
    ...
  ],
};
```

ページ内で画像を参照しているのはこの `PHOTOS` 定数だけなので、ここを直せば全箇所に反映されます。

## 現在使用中のファイル

GALLERY セクションで、サムネイルが横に流れ続けるマーキーとして表示されます。

| ファイル | 推奨比率 | 想定被写体 |
|---|---|---|
| `slide-01` | 16:9 | 出張買取の様子 |
| `slide-02` | 16:9 | 家電・デジタル機器の査定 |
| `slide-03` | 16:9 | 倉庫・在庫品の整理 |
| `slide-04` | 16:9 | スタッフの丁寧な対応 |

推奨サイズ：1600 × 900 px 以上。
枚数は自由に増減できます（`PHOTOS.slides` の配列に足す／減らすだけ。
マーキーは自動でループ幅を調整します）。
