# 写真素材（差し替え用）

リユース事業ページ（`business-reuse.html`）で使用する写真の置き場所です。
現在入っているファイルはすべて **仮のプレースホルダー** で、実写に差し替える前提です。

## 差し替え手順

1. このフォルダに、同じファイル名で実写を置く（拡張子は `.jpg` / `.webp` などでOK）
2. `reuse-lp.jsx` 冒頭の `PHOTOS` 定数でパスと `alt` を書き換える

```js
const PHOTOS = {
  slides: [
    { src: "assets/photos/gallery-01.jpg", alt: "倉庫に積まれた家電の在庫" },
    ...
  ],
};
```

ページ内で画像を参照しているのはこの `PHOTOS` 定数だけなので、ここを直せば全箇所に反映されます。

## 現在使用中のファイル

GALLERY セクションで、サムネイルが横に流れ続けるマーキーとして表示されます。

| ファイル | 比率 | 被写体 |
|---|---|---|
| `gallery-01.jpg` | 16:9 | 倉庫に積まれた家電の在庫 |
| `gallery-02.jpg` | 16:9 | コンテナで仕分けたホビー・ゲーム商品 |
| `gallery-03.jpg` | 16:9 | 棚に並ぶ家電・PC周辺機器の在庫 |

書き出し設定：**1280 × 720 px / JPEG 品質 82**。表示枠は 320px（SP 220px）なので
これで 2 倍解像度まで足ります。元画像から変換する場合は次のコマンドで揃えられます。

```bash
sips -s format jpeg -s formatOptions 82 -Z 1280 元画像.png --out assets/photos/gallery-04.jpg
```

枚数は自由に増減できます（`PHOTOS.slides` の配列に足す／減らすだけ。
マーキーは自動でループ幅を調整します）。
